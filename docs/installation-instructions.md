# SpotiBye Installation Instructions

## System Requirements

### Supported Operating Systems
- **Windows**: Windows 10 or later
- **macOS**: macOS 10.15 (Catalina) or later  
- **Linux**: Ubuntu 18.04+, Fedora 30+, or equivalent

### Hardware Requirements
- **RAM**: Minimum 4GB, recommended 8GB
- **Storage**: 500MB free space
- **Network**: Stable internet connection required

### Software Requirements
- **Browser**: Chrome, Firefox, Safari, or Edge for authentication
- **Account**: Active Spotify Premium or Free account

## Installation Steps

### Step 1: Download SpotiBye

1. Visit the official SpotiBye download page
2. Select your operating system
3. Download the appropriate installer

### Step 2: Install the Application

#### Windows
1. Run the downloaded `.exe` installer
2. Follow the installation wizard
3. Launch SpotiBye from Start Menu

#### macOS
1. Open the downloaded `.dmg` file
2. Drag SpotiBye to Applications folder
3. Launch from Applications folder
4. Accept any security prompts if needed

#### Linux
1. Extract the downloaded `.tar.gz` file
2. Run the install script: `sudo ./install.sh`
3. Launch from your applications menu

### Step 3: First Launch

1. Open SpotiBye
2. Click "Login with Spotify"
3. Complete Spotify authentication in your browser
4. Return to SpotiBye - you're ready to go!

## Verification

To verify installation is successful:
1. SpotiBye opens without errors
2. You can see the login screen
3. Authentication opens your browser
4. Your playlists load after login

## Troubleshooting Installation

### Windows Issues
- **"Windows protected your PC"**: Click "More info" then "Run anyway"
- **Antivirus blocking**: Add SpotiBye to antivirus exceptions

### macOS Issues
- **"Cannot be opened"**: Go to System Preferences > Security & Privacy > Allow
- **"Damaged app"**: Re-download the installer

### Linux Issues
- **Permission denied**: Use `chmod +x` on the installer
- **Missing dependencies**: Install required system packages

## Updating SpotiBye

SpotiBye will notify you when updates are available:
1. Click the update notification
2. Download and install the new version
3. Your settings and data are preserved

## Uninstallation

### Windows
1. Use "Add or remove programs" in Settings
2. Select SpotiBye and click Uninstall

### macOS
1. Drag SpotiBye from Applications to Trash
2. Empty Trash to complete removal

### Linux
1. Run: `sudo ./uninstall.sh`
2. Or manually delete the installation directory
