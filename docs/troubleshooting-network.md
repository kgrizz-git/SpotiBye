# SpotiBye Troubleshooting Guide

## Network Connection Issues

### "Unable to connect to backend"

**Symptoms**: Error message about backend connection, loading indicators that never complete

**Causes**: No internet connection, firewall blocking access, backend temporarily unavailable

**Solutions**:
1. Check your internet connection
2. Try loading a website in your browser
3. Restart SpotiBye
4. Check if you're behind a corporate firewall
5. Try again in a few minutes

### "Request timed out"

**Symptoms**: Operations taking too long, timeout error messages

**Causes**: Slow internet, large playlists, network congestion

**Solutions**:
1. Check your internet speed
2. Try with smaller playlists first
3. Restart your router if needed
4. Try during off-peak hours

### Authentication Issues

### "Authentication failed"

**Symptoms**: Login doesn't work, token errors

**Causes**: Expired session, browser issues, network problems

**Solutions**:
1. Clear your browser cache
2. Try login again
3. Check browser popup blockers
4. Ensure Spotify account is active

### "Invalid redirect URI"

**Symptoms**: Spotify authorization page shows error

**Causes**: Outdated app version, configuration issues

**Solutions**:
1. Update to latest SpotiBye version
2. Restart the application
3. Contact support if persists

## Performance Issues

### Slow Loading

**Symptoms**: Playlists take long time to load

**Causes**: Large playlists, slow connection, first-time load

**Solutions**:
1. Be patient with large playlists (>1000 tracks)
2. Check internet speed
3. Try loading smaller playlists first

### Memory Usage

**Symptoms**: Application becomes slow, high memory usage

**Causes**: Many large playlists loaded, memory leaks

**Solutions**:
1. Close playlists you're not using
2. Restart SpotiBye periodically
3. Check for app updates
