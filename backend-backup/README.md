# SpotiBye Backend API Server

Backend API server for the SpotiBye Spotify Playlist Exporter.

## Setup

1. Copy `.env.example` to `.env` and configure your Spotify API credentials
2. Install dependencies: `pip install -r requirements.txt`
3. Run the server: `python -m spotibye_backend.main`

## API Documentation

Once running, visit `http://localhost:8000/docs` for interactive API documentation.
